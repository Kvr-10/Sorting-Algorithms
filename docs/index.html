How to Use VizNum

Follow these steps to get started with the sorting algorithm visualizer

1

Download and Install

Download the VizNum.exe file from our website and run the installer. No additional dependencies are required.

2

Launch the Application

Open VizNum from your Start menu or desktop shortcut. The application will load immediately with a default dataset.

3

Select an Algorithm

Choose from the available sorting algorithms on the main-screen menu. Each selection will display a brief description.

4

Customize Your Dataset

Enter numbers directly in the input field (comma separated, e.g., "5,2,9,1,7")

5

Start Visualization

Click "Sort" to begin the animation. The current element being processed is highlighted in real-time with distinct colors, while the final sorted array is displayed in green when complete.

6

Explore Learning Resources

Click "How It Works" for step-by-step explanations or "Time Complexity" to understand algorithm performance characteristics.
